# Agent Notes - 决策记录

记录影响代码库的决策--代码和文档承载不了的"为什么"和"放弃了什么"。

## 路径即状态

每条 note 一个文件:`{lifecycle}/yyyy-mm-dd-topic.md`

| 目录 | 含义 |
|------|------|
| `proposed/` | 提案：实现前的决策，还没落地 |
| `implemented/` | 已落地：记录决定了什么 + 否决了什么，**与代码保持同步**（代码改名/移动时同步更新事实） |
| `rejected.md` | 否决：考虑过但拒绝了。只在“能防止未来重复踩坑”时保留（合并为单文件） |
| `archived/` | 归档：冻结，永久不可改，不再是当前权威 |

## 配套规则

- **每次非平凡变更必须写 / 更新一条 note**。变更影响行为、架构、共享契约、流程时适用;纯机械或本地编辑豁免。更新已有 note 而非新建重复
- **不建中央索引**。浏览目录即索引
- **写当前状态,不写历史**。"previously / now / no longer"禁入持久散文;变更故事进 commit,不进 note
- 被完全取代的 note 可合并进新 note 后删除(保留其全部理由);部分取代则保留并交叉链接
- 日期 = 主题**首次提出**的日期
